Connecting to the gateway…

REQUEST
  1. 01 Rate limit Token bucket per client IP — configured for 100 requests / 60s here. Over the limit gets a 429 with a Retry-After header.
  2. 02 Route match Longest-prefix-wins path matching. No match is a clean 404 — it never reaches the auth check.
  3. 03 Auth X-API-Key header check. Runs after routing on purpose, so an unmatched path is always 404, never 401.
  4. 04 Load balance Health-aware round robin across the backend pool. Zero healthy backends means a 502, not a hang.
  5. 05 Forward Proxies to the chosen backend. The write-ahead log records start and finish independently of the access log.
